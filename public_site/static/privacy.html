Privacy and use

Document review reads selected PDF, XLSX and DOCX files in your browser’s memory. File contents, names, comparison settings and findings stay in the tab. The browser requests site assets and any example files you choose to run.

Use Clear to discard the current review, Cancel to stop a running review, or close the tab. Example files are labeled synthetic or official on the examples page.

Check each finding against its source before using it in a financial decision. The case walkthrough uses synthetic data and simulated actions.

IAF questions

IAF receives questions typed into its chat form and uses a library of public project information. If model selection is enabled, the provider receives project excerpts and matching topic cues. Document review runs separately.
