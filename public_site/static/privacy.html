Privacy and use

The PDF explainer reads selected files in memory in your browser. Sentinel does not send your document, file name, extracted text, or findings to a server, or store them in browser storage. Your browser still requests the site, its static scripts, and the synthetic sample when you choose it.

Clear the result or close the tab to remove the document from the interface. The example document and recorded case contain synthetic data.

This project is for demonstration and research. Check any finding against its source before using it in a financial decision.
