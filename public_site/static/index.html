How Sentinel investigates fraud

Sentinel is a research workbench for fraud analysts. The public walkthrough follows a synthetic case recorded from the local app.

Start a live demo case ↗ Walk through the recorded case ↗
  1. Ingest and score. Store the transaction and evaluate its amount and recent account activity using rules or the bundled model.
  2. Investigate. For a flagged transaction, review stored evidence. The workbench can record investigator, analyst and reviewer steps.
  3. Review the proposal. A person decides whether to approve or reject. The trace shows the evidence and the recommendation.
  4. Execute and audit. The approved action is simulated. The audit records what happened and a retry returns the original result.

How Sentinel was built and tested

  • Tested with three different invoices

    The PDF checks distinguish incorrect math, payments close to a stated approval limit and a request to change bank details. Findings point back to the page that triggered them.

  • Training data you can inspect

    We generated 82,819 transactions and used separate time periods to train, tune and test the model. See what went into the dataset.

  • Approval before any action

    The recorded case shows when the app opened a case, checked evidence, required approval and executed one simulated action. Repeating the request returns the same action.

Before you start

Where does my PDF go?

The file and its extracted text stay in the browser tab. Clear the result or close the tab to remove it from the page.

What files work here?

Use a text PDF up to 10 MB and 40 pages. Password protected PDFs are unsupported. Image only pages need OCR, which this tool does not include.

What do the findings mean?

They explain terms and show the math on readable invoice rows. The browser also flags changes in payment instructions and compares amounts with a threshold explicitly stated in the document. Confirm entities, policy and account information using trusted records.

Does this use ChatGPT or Claude?

The PDF explainer uses local text extraction and rules. The recorded case uses deterministic roles. Both tools work without a model account or key.

What data trained the model?

Sentinel's bundled model was trained on generated transactions with synthetic account histories and known labels. The sample PDF and public case are also synthetic. The ULB and Worldline dataset was acquired separately for research.

Download the synthetic training dataset (6.4 MiB ZIP) · Dataset contents and verification

Can I run the full workbench here?

Yes. Open the live workbench to investigate and approve a simulated action on a temporary synthetic case. The PDF explainer runs in your browser. The local app also supports CSV and XLSX.
