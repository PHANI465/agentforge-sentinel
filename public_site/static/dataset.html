Synthetic model dataset

The p1 snapshot has 82,819 generated transactions across 600 fictional accounts, with 581 synthetic fraud labels in the full snapshot. It includes the chronological training, validation and test periods.

Download the dataset (6.4 MiB ZIP)

What is inside?

  • Accounts and transactions in JSON Lines format.
  • Fraud labels and label availability times, for offline evaluation.
  • Features available when a transaction was scored, plus a manifest with checksums.

The model used only the eligible training rows and their known labels. The snapshot includes held out evaluation rows so researchers can reproduce the split and evaluate the model.
