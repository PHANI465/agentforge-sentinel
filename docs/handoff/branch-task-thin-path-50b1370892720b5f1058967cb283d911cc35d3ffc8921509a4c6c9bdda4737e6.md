## Implemented

- **R1:**
  - the Claude child environment drops every `ANTHROPIC_*` and `CLAUDE_CODE_USE_*` variable plus `AWS_BEARER_TOKEN_BEDROCK`;
  - before any model call, a preflight `claude auth status --json` must report `loggedIn/claude.ai/firstParty`, otherwise it fails closed;
  - `--disable-slash-commands` added.
- **R2:** execution reads `now` after the approval and case locks. Investigation also reads it after the case lock.
- **R3:** per-account advisory lock, then the decision time. Velocity counts only `ingested_at <= now`. Same-timestamp events are excluded.
- **R4:** replay requires current execution authority (`require_execution_authority`, factored out of the pure guard). Freshness is not rechecked.
- **R5:** a `ScoringOutcome` contract and `scoring_outcomes` table (migration 0002) for every ingestion. Replay returns the stored outcome.
- **R6:** `read_limited`: declared oversize gets 413 unread; the stream stops consuming past 16 KiB.
- **R7:** `run_concurrently` (futures, bounded results, re-raise) and exact per-caller outcome assertions, plus helper self-tests.
- **R8:** a lapsed unused approval reopens the case at a new revision (`approval_expired`, a new AuditEvent type), on execution denial or an investigate request. The old approval stays unusable.
- **Follow-ups:** conftest cleanup covers all post-start setup; the per-test DSN uses `make_conninfo`; schema export writes and compares exact LF bytes; the dependency-age comment is scoped.
