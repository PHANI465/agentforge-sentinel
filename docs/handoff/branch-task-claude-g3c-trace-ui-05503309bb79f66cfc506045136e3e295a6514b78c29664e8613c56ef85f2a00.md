## Implemented

- A strict v1.2 parser (web/src/api/trace.ts) and `client.trace` (GET only, optional abort).
- A read-only TracePanel under the case file. It shows honest empty, legacy, zero-role,
  running, overdue and recovered states; attempts keyed by run id; untrusted claims next to
  server checks; unknown values kept unknown; per-process limits; steps; and identifiers in
  details. See docs/ui/G3C-trace.md.
- `useTrace` fences each response by generation, case and selection, with aborts. Old
  content is cleared on context change. An explicit selection survives refresh. The trace
  re-reads after mutations and 409 re-reads. Snapshot revision mismatches are labelled.
- CaseFile no longer says "No investigation has been recorded" when the trace shows a
  workflow.
- A separate `npm run test:e2e:trace` run: the test-only three-role factory, seed and
  inspect helpers, and 10 browser cases. The default 19-case run's start arguments are
  unchanged.
